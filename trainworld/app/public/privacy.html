プライバシーについて

更新：2026年11月17日

このサイトは aomona の協力プレイ版です。原作は circularsquare/trainsworld です。

端末に保存するもの

ローカルセーブと表示設定はブラウザーの IndexedDB / localStorage に保存します。参加用パスワードの認証後は、有効期間7日の HttpOnly・SameSite Cookie を使います。パスワードそのものを端末の保存領域には保存しません。

協力プレイで共有するもの

プレイヤー名、路線網、資金、ゲームの進行、操作履歴、カーソル位置とカーソル会話を同じルームの参加者に共有します。共有状態は Cloudflare Durable Objects に保存されます。ルームへの最後の参加から7日後に削除する設計ですが、処理遅延や障害により削除が遅れる場合があります。大切なセーブは端末に保存・ダウンロードしてください。

接続先

このサイトの配信と通信には Cloudflare を使います。IPアドレス等の接続情報や技術的なログが同社で処理されます。地図は OpenFreeMap、ゲームの地理データは data.anita.garden 等から直接取得します。これらの提供者にも接続情報が送られます。このフォークは原作のアカウント・課金サービスとは独立しています。

参加と連絡

ルームの参加には共有パスワードと招待リンクが必要です。参加者は相互に信頼できる人に限定してください。連絡は このフォークの GitHub Issues で受け付けます。公開の Issue にパスワードや秘密情報を書かないでください。
